## Задание 1
Класс Money:
- поля: unsigned int rubles, short int kopeks;
- метод: сравнение двух объектов типа Money, результат — bool.

### Алгоритм решения

1. **Поля класса:** unsigned int rubles (рубли), short int kopeks (копейки, 0..99).
2. **Свойства:** геттеры get_rubles(), get_kopeks(); сеттеры set_rubles(), set_kopeks() с проверкой диапазона копеек.
3. **Конструкторы (4 шт.):**
   - по умолчанию — 0 руб. 0 коп.;
   - с параметрами — Money(unsigned, short) с валидацией копеек;
   - копирования — Money(const Money&);
   - из double — через llround(amount * 100) для корректного округления.
4. **Перегрузка operator<<** — вывод в формате "X руб. Y коп.".
5. **Метод equals(const Money&)** — сравнение двух объектов, возвращает bool.
6. **Вспомогательный метод normalize()** — перенос 100 копеек в рубль.
7. **Метод is_valid()** — проверка корректности (0 <= kopeks <= 99).
8. **Метод subtract()** — вычитание сумм (задел под Задание 2), бросает runtime_error при отрицательном результате.
9. **Ввод с клавиатуры** — функция InputVal(int&), которая при ошибке очищает поток и просит повторить. Валидация диапазона — через while + continue.
10. **Дружественный интерфейс** — меню из 8 пунктов, каждый тестирует соответствующий конструктор/метод.
